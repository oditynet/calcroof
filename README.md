# calcroof

Калькулятор для резки стропил
У нас есть мауэрлат и коньковая балка. Надо сделать запил в коньке и на мауэрлате и чтоб стропила легла ровно. 
2 и 3 этап помогают сделать запил, зная скат кровли.
В 4 этапе просто делается отступ и 5 этап повторяется как 2 и 3
